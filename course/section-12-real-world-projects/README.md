# Section 12: Real World Projects

This section provides conceptual and architectural walkthroughs for building production-grade applications.

## Project 1: Notes App
- **Features:** Create, Edit, Delete, Search notes.
- **Stack:** MVVM, Room Database, LiveData, RecyclerView.
- **Focus:** Local persistence and UI state management.

## Project 2: Secure DNS Android App
- **Features:** Encrypt DNS queries (DoH/DoT).
- **Stack:** VpnService API, Retrofit (for DoH), Java Concurrency.
- **Focus:** Networking internals and system-level APIs.

## Project 3: File Manager
- **Features:** Browse directories, Rename, Delete, Move files.
- **Stack:** Storage Access Framework (SAF), File I/O, RecyclerView.
- **Focus:** Android File System and Scoped Storage.

## Project 4: Chat Application
- **Features:** Real-time messaging, User Authentication.
- **Stack:** Firebase Realtime Database/Firestore, Cloud Messaging (FCM).
- **Focus:** Real-time data synchronization and cloud integration.

## Project 5: Offline-First Database App
- **Features:** Work without internet, sync when online.
- **Stack:** Room, WorkManager, Retrofit, Repository Pattern.
- **Focus:** Synchronization strategies and data consistency.

Choose one of the projects above and implement it from scratch, following the Clean Architecture and SOLID principles learned throughout this course.
