# Module 12: Real World Projects - Part 2

## Project 3: File Manager

### Overview
Mastering the Android File System and Permissions.

### Key Features
- Browsing Internal and External storage.
- **Scoped Storage**: Using the Storage Access Framework (SAF) for user-selected directories.
- **RecyclerView**: Displaying files with different icons based on MIME types.
- **File I/O**: Implementing copy, move, and rename operations.

## Project 4: Chat Application (Real-time)

### Overview
Mastering Networking and Concurrency.

### Core Technologies
- **WebSockets**: For two-way real-time communication.
- **Retrofit**: For user authentication and profile management.
- **Service**: A background service to listen for incoming messages when the app is closed.

---

## Project 5: Offline First Database App

### Overview
Mastering Data Sync and Advanced Architecture.

### Core Technologies
- **WorkManager**: To sync local changes to a remote server when the internet is available.
- **Room**: Local cache.
- **Repository Pattern**: Implementing the "Cache-then-Network" strategy.

Choose one project and implement the "Notes App" with Hilt for Dependency Injection and Room for persistence.
